# Todo Management System

A simple and efficient Todo Management System built using **Spring Boot**. This application allows users to create, update, delete, and manage their daily tasks through a user-friendly interface.

## Features

* Create new tasks
* View all tasks
* Update existing tasks
* Delete tasks
* Mark tasks as completed
* Responsive and easy-to-use interface

## Tech Stack

* Java
* Spring Boot
* Spring MVC
* Thymeleaf
* Maven
* HTML, CSS, JavaScript

## Getting Started

### Prerequisites

* Java 17 or later
* Maven

### Installation

1. Clone the repository:

   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```
   cd todo-management-system
   ```

3. Run the application:

   ```
   mvn spring-boot:run
   ```

4. Open your browser and visit:

   ```
   http://localhost:8080
   ```
